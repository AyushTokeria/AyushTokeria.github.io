# ayushtokeria.github.io

Personal site, served from the root of `https://ayushtokeria.github.io` by GitHub Pages.

- **Change what it says:** edit `src/content.ts` (experience, projects, skills, links, dates). Everything else is layout.
- **Deploy:** push to `main`. `.github/workflows/web.yml` builds with Vite and publishes to Pages.
- **One-time setting:** *Settings → Pages → Source: GitHub Actions*.
- **Local preview:** `npm install && npm run dev`.
